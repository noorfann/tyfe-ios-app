# Project workflows

These are on-demand reference workflows for recurring changes in this project. They are not a replacement for `AGENTS.md` and do not assume a particular agent's command, model, tool, or memory system. Read the matching workflow before starting that kind of change, then follow the repository rules and user request.

| Workflow | Use when |
|---|---|
| [`creating-screen/SKILL.md`](creating-screen/SKILL.md) | Adding a VIPER screen |
| [`creating-manager/SKILL.md`](creating-manager/SKILL.md) | Adding a Manager or service |
| [`creating-component/SKILL.md`](creating-component/SKILL.md) | Adding a reusable SwiftUI component |
| [`creating-model/SKILL.md`](creating-model/SKILL.md) | Adding a Codable model or enum |
| [`creating-test/SKILL.md`](creating-test/SKILL.md) | Adding Swift Testing coverage |
| [`creating-module/SKILL.md`](creating-module/SKILL.md) | Adding a top-level navigation module |
| [`creating-ab-test/SKILL.md`](creating-ab-test/SKILL.md) | Adding an experiment or feature flag |
| [`creating-view-modifier/SKILL.md`](creating-view-modifier/SKILL.md) | Adding a reusable ViewModifier |
| [`creating-extension/SKILL.md`](creating-extension/SKILL.md) | Adding a type extension |
| [`adding-package/SKILL.md`](adding-package/SKILL.md) | Adding a Swift Package dependency |
| [`adding-deep-link/SKILL.md`](adding-deep-link/SKILL.md) | Adding deep-link or push routing |
| [`creating-paywall/SKILL.md`](creating-paywall/SKILL.md) | Adding a paywall variant |
| [`refactoring-screen/SKILL.md`](refactoring-screen/SKILL.md) | Renaming or restructuring a screen |

The `SKILL.md` filename is retained to keep the workflow references stable. These files are project documentation; use an installed Codex skill only when the current environment provides one and it fits the task.
