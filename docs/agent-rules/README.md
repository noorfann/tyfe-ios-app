# Agent rules

These documents are the detailed, repository-specific rules referenced by `AGENTS.md`. Read the smallest relevant set for the task; `AGENTS.md` remains the top-level source of truth when guidance overlaps.

| Rule | Read when |
|---|---|
| [`viper-architecture.md`](viper-architecture.md) | Adding or changing a screen, Presenter, Interactor, Router, Builder, or Component |
| [`project-structure.md`](project-structure.md) | Choosing file locations, naming, navigation modules, previews, or build configuration |
| [`swift-6.md`](swift-6.md) | Writing Swift models, async code, actors, tests, or concurrency-sensitive code |
| [`swiftui-patterns.md`](swiftui-patterns.md) | Writing or reviewing SwiftUI views, components, modifiers, or previews |
| [`manager-lifecycle.md`](manager-lifecycle.md) | Adding or changing a Manager, service, dependency registration, login, or logout |
| [`commit-rules.md`](commit-rules.md) | The user explicitly requests a commit |

These rules describe the current project conventions, not a specific agent product. If the codebase and a rule disagree, verify the existing implementation and make the smallest deliberate correction; mention the discrepancy in the handoff.
